Installation:

```
pip install -U pytest
```

Running pytest:

```
pytest testFile.py
```

- pytest will run all files of the form test\__.py or _\_test.py in current and subdirectory
- Tests can be defined using just a method, or grouped together using a class
- Class name needs to be prefixed with **Test**

## Overview

Explored transfer learning techniques using the KITTI dataset to improve model performance on self-driving car perception tasks where real-world data is scarce.

**Technologies:** PyTorch, Python, Computer Vision

**Key contributions:**
- Evaluated and compared multiple computer vision tasks: depth estimation, semantic segmentation, and object detection
- Analyzed how synthetic data can supplement limited real-world training data
- Demonstrated transfer learning effectiveness across different vision domains

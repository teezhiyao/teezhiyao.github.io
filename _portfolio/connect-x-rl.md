## Overview

Built and trained various reinforcement learning models to play Connect 4, using PyTorch. Awarded best course project in the Deep Learning coursework at SUTD.

**Technologies:** PyTorch, Python, React (frontend)

**Key contributions:**
- Implemented Alpha Zero and Deep Q-Network (DQN) architectures
- Trained and compared model performance across different RL approaches
- Built an interactive web-based frontend to play against the trained models

## Overview

Finalist in the Singapore Airlines App Challenge 2018 (Student Category, Top 6). Developed a prototype for inventory management using a combination of hardware and software.

**Technologies:** Raspberry Pi, Firebase, Python (Kivy, Django)

**Key contributions:**
- Integrated hardware (Raspberry Pi) with cloud backend (Firebase)
- Built Python-based frontend and backend (Kivy + Django)
- Presented functional prototype to Singapore Airlines judges
